# Code of Conduct

## Our standard

Contributors and maintainers are expected to be respectful, direct, and
constructive. Technical disagreement is welcome; harassment, discrimination,
personal attacks, doxxing, and deliberate exposure of private data are not.

## Enforcement

Report unacceptable behavior privately to the repository owner through the
contact method listed on the owner’s GitHub profile. Reports will be reviewed
and handled in confidence where possible.
